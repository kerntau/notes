## 一、程序填空题（每题 6 分，每空 3 分）

### 1. 统计单词数量
编写程序统计字符串 `s` 中单词的个数：

```c
void main()
{
    char s[100];
    gets(s);
    int c=0, i, f=1, n=strlen(s);
    for (i=0; i<n; i++)
    {
        if (1. _____________)
            f=1;
        else if (s[i]!=' ' && f==1)
        {
            c++;
            f=0;
        }
    }
    2. _____________;
}
```

<details>
<summary>查看参考答案与解析</summary>
<div style={{ padding: '1rem', marginTop: '0.5rem', borderRadius: '6px', backgroundColor: 'var(--ifm-color-emphasis-100)' }}>

- **空 (1)**：`s[i] == ' ' && f == 0`
- **空 (2)**：`printf("%d", c);`
- **解析**：当遇到空格且标志 `f` 为 0 时，重置 `f = 1` 标记单词间隔；统计完成后输出单词总数 `c`。
</div>

### 2. 查找特定字符下标
输入字符串 `s` 和字符 `ch`，查找 `ch` 在 `s` 中首次出现的下标：

```c
#include <stdio.h>
#include <string.h>

void main()
{
    char s[100], ch;
    scanf("%s %c", s, &ch);
    int i, n=strlen(s);
    for (i = 0; 1. _____________;)
        i++;
    if (2. ____________)
        printf("没有找到");
    else
        printf("ch 的下标是%d", i);
}
```

<details>
<summary>查看参考答案与解析</summary>
<div style={{ padding: '1rem', marginTop: '0.5rem', borderRadius: '6px', backgroundColor: 'var(--ifm-color-emphasis-100)' }}>

- **空 (1)**：`s[i] != '\0' && s[i] != ch`
- **空 (2)**：`i >= n` 或 `s[i] == '\0'`
- **解析**：循环在未到达字符串末尾且未查找到 `ch` 时继续递增；若循环结束后 `i >= n` 说明末尾仍未匹配到目标字符。
</div>
</details>

### 2. 抛硬币模拟函数（20 分）
编写 `flip()` 无参数函数返回随机数 1（正面）或 0（反面），主函数循环 10 次输出正面或反面（每行 5 个），最后统计并输出正反面出现的总次数。

<details>
<summary>查看参考代码与解析</summary>
<div style={{ marginTop: '0.5rem' }}>

```c
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

int flip() { return rand() % 2; }

int main() {
    srand(time(NULL));
    int heads = 0, tails = 0;
    printf("抛硬币结果：\n");
    for (int i = 1; i <= 10; i++) {
        int res = flip();
        if (res == 1) { printf("正面 "); heads++; }
        else { printf("反面 "); tails++; }
        if (i % 5 == 0) printf("\n");
    }
    printf("\n统计结果：正面%d次，反面%d次\n", heads, tails);
    return 0;
}
```

### 3. 递归求解 e 的近似值（20 分）
计算 *e* 的近似值：`e = 1 + 1/1! + 1/2! + ... + 1/n!`，直到某项绝对值小于 1e-7，要求阶乘使用递归函数 `facn` 实现。

<details>
<summary>查看参考代码与解析</summary>
<div style={{ marginTop: '0.5rem' }}>

```c
#include <stdio.h>
#include <math.h>

double fac(int n) {
    if (n == 0 || n == 1) return 1.0;
    return n * fac(n - 1);
}

int main() {
    double e = 1.0, term;
    int n = 1;
    do {
        term = 1.0 / fac(n);
        e += term;
        n++;
    } while (fabs(term) >= 1e-7);
    printf("最终结果：e ≈ %.8f (n=%d时满足精度)\n", e, n - 1);
    return 0;
}
```

### 4. 单链表创建与连接（30 分）
定义两个单链表，使用 `creat()` 函数创建，并编写 `contracte()` 函数将链表二连接到链表一的末尾。

<details>
<summary>查看参考代码与解析</summary>
<div style={{ marginTop: '0.5rem' }}>

```c
#include <stdio.h>
#include <stdlib.h>

typedef struct Node {
    int data;
    struct Node* next;
} Node;

Node* creat() {
    Node *head = NULL, *tail = NULL, *p = NULL;
    int num;
    printf("请输入整数创建单链表（-1退出）：\n");
    while (1) {
        scanf("%d", &num);
        if (num == -1) break;
        p = (Node*)malloc(sizeof(Node));
        p->data = num;
        p->next = NULL;
        if (head == NULL) { head = tail = p; }
        else { tail->next = p; tail = p; }
    }
    return head;
}

Node* contracte(Node* list1, Node* list2) {
    if (list1 == NULL) return list2;
    Node* p = list1;
    while (p->next != NULL) p = p->next;
    p->next = list2;
    return list1;
}
```

</div>
</details>
