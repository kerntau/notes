# 创建博客文章

Docusaurus 会为**每篇博客文章生成独立页面**，同时还会自动生成**博客列表索引页**、**标签分类系统**以及 **RSS 订阅源**...

## 发布你的第一篇博客

在 `blog/2021-02-28-greetings.md` 创建一个 Markdown 文件：

```md title="blog/2021-02-28-greetings.md"
---
slug: greetings
title: 问候！
authors:
  - name: Joel Marcey
    title: Docusaurus 联合创作者
    url: https://github.com/JoelMarcey
    image_url: https://github.com/JoelMarcey.png
tags: [问候]
---

恭喜你，你成功发布了第一篇博客文章！

你可以随意编辑和修改这篇文章。
```

现在访问 [http://localhost:3000/blog/greetings](http://localhost:3000/blog/greetings) 即可预览。
