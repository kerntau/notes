# 《C程序设计》科目简介

湖北师范大学专升本计算机科学与技术专业的专业课考试科目为 **《高级语言程序设计》**（在备考和实际招考中通常简称为 **《C程序设计》**）。作为该专业选拔的**唯一专业课**，它不仅是测试考生工科逻辑基础和程序设计能力的核心科目，更是在专升本总分屏障中拉开分差、决定录取的“分水岭”。

## 2. 核心考核范围与要求

该科目主要考核学生对 C 语言基本语法、语义及各种数据类型使用特点的理解。要求考生不仅要掌握基础理论，更要在实践上具备扎实的 **算法设计、程序调试和手写代码的能力**。

### 基础与控制结构
- **语法规范**：标识符命名规则、常见数据类型存储长度、运算符优先级与结合性。
- **流程控制**：`if` 嵌套、`switch-case` 多分支及 `while`、`for` 循环结构的嵌套与跳转控制。

### 批量数据与内存管理
- **数组机制**：一维、二维数组的定义、内存布局与初始化。
- **指针核心**：指针变量的应用、指针与数组/函数的结合（尤其是通过指针修改实参的机制）。

### 模块化与自定义类型
- **函数调用**：形参与实参传递、变量作用域与生存期（如 `static` 静态局部变量在函数调用中的值保留特性）。
- **复合结构**：`struct` 结构体定义、**单链表**的创建、遍历与节点插入删除操作。

## 3. 试题题型特征

湖北师范大学《C程序设计》真题呈现高度标准化的 **非客观题** 结构，主要包含以下四大模块：

1. **程序填空**
   - 考查对算法关键步骤和常用库函数（如 `strlen`, `strcmp`, `strcpy` 等）的精确补全。
2. **程序改错**
   - 考查语法细节、格式占位符（例如 `scanf` 中漏写取地址符 `&`，或 `double` 类型错用 `%f` 代替 `%lf` 接收输入）与逻辑漏洞的纠错能力。
3. **程序结果计算**
   - 通过追踪循环、静态变量、递归或指针地址计算，推导程序最终的输出结果。
4. **程序题（算法设计）**
   - 要求在**没有 IDE 辅助**的纸笔作答环境下，手写出逻辑完整、规范（必须包含头文件）且具备鲁棒性的完整 C 语言代码。
