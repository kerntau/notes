# 教程简介

让我们在 **5 分钟内了解 Docusaurus**。

## 快速上手

通过**创建一个新站点**开始使用。

或者直接在 **[docusaurus.new](https://docusaurus.new)** 上**在线体验 Docusaurus**。

### 环境准备

- [Node.js](https://nodejs.org/zh-cn/download/) 20.0 及以上版本。

## 本地启动

运行开发服务器：

```bash
pnpm start
```

该命令会在本地构建网站并启动开发服务器，在浏览器打开 http://localhost:3000/ 即可实时预览。
