# 网站多语言翻译

下面以将 `docs/intro.md` 翻译为法语（French）为例展示如何国际化。

## 配置 i18n

修改 `docusaurus.config.ts` 添加对 `fr` 语言的支持：

```ts title="docusaurus.config.ts"
export default {
  i18n: {
    defaultLocale: 'zh-Hans',
    locales: ['zh-Hans', 'en', 'fr'],
  },
};
```

## 翻译文档

将 `docs/intro.md` 复制到 `i18n/fr` 目录：

```bash
mkdir -p i18n/fr/docusaurus-plugin-content-docs/current/

cp docs/intro.md i18n/fr/docusaurus-plugin-content-docs/current/intro.md
```

在 `i18n/fr/docusaurus-plugin-content-docs/current/intro.md` 中编辑法语内容。

## 启动本地化站点

使用指定语言环境启动站点：

```bash
pnpm start --locale fr
```

可以在 [http://localhost:3000/fr/](http://localhost:3000/fr/) 访问对应的法语本地化页面。

:::caution[注意]

在开发模式下，服务器一次只能启动单一种语言环境。

:::

## 添加语言切换下拉菜单

在导航栏添加语言选择下拉控件：

```ts title="docusaurus.config.ts"
export default {
  themeConfig: {
    navbar: {
      items: [
        {
          type: 'localeDropdown',
          position: 'right',
        },
      ],
    },
  },
};
```
