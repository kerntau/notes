# Deploy Your Site

Docusaurus is a **static-site generator** (also called **[Jamstack](https://jamstack.org/)**).

It builds your site as pure **static HTML, JavaScript, and CSS files**.

## Build for Production

Build your website for **production**:

```bash
pnpm build
```

The static files will be generated in the `build` folder.

## Local Preview and Deployment

Test your production build locally:

```bash
pnpm serve
```

Now visit [http://localhost:3000/](http://localhost:3000/) to preview the contents of the `build` folder.

You can now easily deploy the `build` folder to **almost any hosting platform** (see the **[official deployment guide](https://docusaurus.io/docs/deployment)** for details).
