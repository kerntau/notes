# Translate Your Site

Below is an example of translating `docs/intro.md` into French to demonstrate internationalization.

## Configure i18n

Modify `docusaurus.config.ts` to add support for the `fr` locale:

```ts title="docusaurus.config.ts"
export default {
  i18n: {
    defaultLocale: 'zh-Hans',
    locales: ['zh-Hans', 'en', 'fr'],
  },
};
```

## Translate a Document

Copy `docs/intro.md` to the `i18n/fr` directory:

```bash
mkdir -p i18n/fr/docusaurus-plugin-content-docs/current/

cp docs/intro.md i18n/fr/docusaurus-plugin-content-docs/current/intro.md
```

Edit the French content in `i18n/fr/docusaurus-plugin-content-docs/current/intro.md`.

## Start Your Localized Site

Start the site with a specific locale:

```bash
pnpm start --locale fr
```

Visit [http://localhost:3000/fr/](http://localhost:3000/fr/) to access the French localized page.

:::caution[Caution]

In development mode, the server can only serve one locale at a time.

:::

## Add a Locale Dropdown

Add a language selector dropdown to the navbar:

```ts title="docusaurus.config.ts"
export default {
  themeConfig: {
    navbar: {
      items: [
        {
          type: 'localeDropdown',
          position: 'right',
        },
      ],
    },
  },
};
```
