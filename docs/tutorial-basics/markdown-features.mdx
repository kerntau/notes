# Markdown 特性

Docusaurus 支持标准 **[Markdown](https://daringfireball.net/projects/markdown/syntax)** 语法以及一系列**扩展特性**。

## Front Matter 元数据

Markdown 文档顶部可使用 [Front Matter](https://jekyllrb.com/docs/front-matter/) 来定义元数据：

```text title="my-doc.md"
// highlight-start
---
id: my-doc-id
title: 文档标题
description: 文档描述
slug: /my-custom-url
---
// highlight-end

Markdown 正文内容
```

## 标题

支持标准 “#” 语法编写标题，标题会自动加到右侧目录中。`#` 的数量对应标题级别。

```md
## 标题名称

正文内容
```

## 链接

支持相对路径和绝对路径的 Markdown 链接：

```md
看看如何 [创建独立页面](./create-a-page.mdx)。
```

**效果：** 看看如何 [创建独立页面](./create-a-page.mdx)。

## 代码块

支持语法高亮与带标题的代码块：

```jsx title="src/components/HelloDocusaurus.js"
function HelloDocusaurus() {
  return <h1>你好，Docusaurus！</h1>;
}
```

## 提示框 (Admonitions)

Docusaurus 拥有特殊的提示框语法：

:::tip[提示]

使用此强大的特性选项

:::

:::danger[警告]

此操作存在一定危险性

:::

## MDX 与 React 组件

[MDX](https://mdxjs.com/) 可以让你的文档更加**交互化**，支持在 Markdown 内直接嵌入 React 组件：

export const Highlight = ({children, color}) => (
  <span
    style={{
      backgroundColor: color,
      borderRadius: '20px',
      color: '#fff',
      padding: '10px',
      cursor: 'pointer',
    }}
    onClick={() => {
      alert(`你点击了颜色 ${color}，内容为 ${children}`);
    }}>
    {children}
  </span>
);

这是 <Highlight color="#25c2a0">Docusaurus 绿色</Highlight>！

这是 <Highlight color="#1877F2">Facebook 蓝色</Highlight>！
