# 创建文档

文档是由以下功能关联起来的**一组页面**：

- **侧边栏导航**
- **上一页/下一页导航**
- **版本控制**

## 创建你的第一份文档

在 `docs/hello.md` 创建一个 Markdown 文件：

```md title="docs/hello.md"
# 你好

这是我的**第一份 Docusaurus 文档**！
```

现在访问 [http://localhost:3000/docs/hello](http://localhost:3000/docs/hello) 即可查看新文档。

## 配置侧边栏

Docusaurus 会根据 `docs` 目录结构**自动生成侧边栏**。

你可以添加 Front Matter 元数据来自定义侧边栏标签与排序：

```md title="docs/hello.md" {1-4}
---
sidebar_label: '问候'
sidebar_position: 3
---

# 你好

这是我的**第一份 Docusaurus 文档**！
```
